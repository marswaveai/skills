| 主题情绪 | 自动配色方向 | 画面倾向 |
|---|---|---|
| 新生、春天、开始、希望 | 雾森青 + 淡粉 + 米白 | 新叶、花影、晨光、上实下虚 |
| 夏日、自由、风、远方 | 海风灰蓝 + 褪白 + 草木绿 | 海平线、草丛、飞鸟、大片天空 |
| 温柔、关系、花、相遇 | 灰粉 + 雾绿 + 暖米色 | 失焦花影、细枝、柔光、偏侧留白 |
| 秋天、成熟、阅读、沉淀 | 麦芽黄 + 琥珀 + 纸米色 + 深棕 | 干草、茶汤光、纸张、垂直中轴 |
| 夜晚、独处、梦、等待 | 深靛蓝 + 灰蓝 + 冷灰白 | 小人物、月光、远处微光、大面积暗部 |
| 告别、回忆、时间、错过 | 灰蓝 + 远山灰粉 + 褪白 | 海、空镜、低对比、远景和留白 |
| 安静、禅意、自然、节气 | 米纸色 + 苔藓绿 + 墨灰 | 蕉叶、飞鸟、宣纸、细线和竖排 |
| 温暖、回家、陪伴、日常 | 暖米色 + 柔棕 + 低饱和橙黄 | 窗光、桌面影子、枝叶、轻颗粒 |
| 压力、迷失、重新整理 | 灰绿 + 深蓝灰 + 一处暖白光 | 雾、下坠线条、远处光源、小比例人物 |

四步逻辑：先定温度 → 再定明度 → 最后定强调色 → 统一材质（低饱和、柔焦、颗粒、哑光）。

## 模式体系（一个基础 + 四个可叠加项）

**基础底色（永远生效）：安静自然**

- 所有海报的共同底层：低饱和、柔焦、大面积留白、轻颗粒、一个主元素、克制文字。不加任何叠加项时，就是最初的谧静自然风格。

**四个可叠加项**（每张最多同时两项；表述写作「安静自然 + 叠加项」）

| 叠加项 | 只改什么 | 加进来会怎样 | 什么时候用 | 触发词示例 |
|---|---|---|---|---|
| 编辑排版 | 版式 | 超大标题、双层画廊结构、细英文基线，更像杂志内页 | 节气专题、品牌月报、系列封面 | 杂志感、标题大一点 |
| 档案图鉴 | 信息结构 | 编号、年份、圆形视窗、图注小字，像标本卡 | 图鉴、研究记录、展览、文创 | 档案、图鉴、编号 |
| 电影夜色 | 光色与明暗 | 整体变深蓝/深绿，暗部颗粒更厚，主体压到低位 | 雨夜、告别、孤独、冬季 | 夜、电影感、暗一点 |
| 实验笔触 | 材质技法 | 刮板颜料、透明叠层、套印偏移，或青柠强调色 | 抽象季节、先锋编辑、当代艺术 | 抽象、实验、颜料 |

组合规则：默认只开基础，不叠；每张最多叠 1–2 项，叠得越多离「安静」越远；推荐「档案图鉴 × 电影夜色」「实验笔触 × 编辑排版」，慎用「档案图鉴 × 实验笔触」。

同一主题下的效果差异（以「霜降」为例）：仅基础 = 雾白雪坡 + 细树影；+编辑排版 = 超大「霜降」压在下方留白处；+电影夜色 = 整体沉入深蓝暮色，树线压到低位。

## 构图骨架

| 骨架 | 做法 | 适合 |
|---|---|---|
| 中轴悬浮 | 背景虚化，标题居中，副文案少量分布 | 春夏、节气、生活方式 |
| 上实下虚 | 上方意象块，下方大面积留白放字 | 生长、寻找方向、秋日 |
| 对角线意象 | 叶/枝/水纹斜穿画面，标题沿空白布置 | 风、雨、迁徙、旅行 |
| 低位地平线 | 地平线在下 1/3，天空占大面积 | 海、远方、告别、自由 |
| 偏侧留白 | 主体占一侧 1/3，另一侧完整呼吸区 | 花、枝叶、品牌 |
| 小人物远景 | 人物极小作比例尺，置于大空间 | 独处、夜晚、回家、等待 |

口诀：先找呼吸区，再放主意象；先定情绪重心，再放标题；宁可空三分，不要满到没有回声。

## 标题设计速查

总原则：无色块衬底、无描边、无发光、无投影；可读性靠画面明暗、同色系和留白。

| 排版骨架 | 做法 | 适用 |
|---|---|---|
| 阶梯错落（最常用） | 行首行尾不对齐，沿对角线逐行下沉，基线微倾 | 诗句式标题、情绪主题 |
| 大小对比 | 一行小字 + 一个核心大字（高 1/4–1/3）或首字放大 | 单字点题 |
| 长笔画贯穿 | 长横长撇拉长出画；书法大字末笔垂落贯穿画面 | 书法、风、动势 |
| 竖排右行 | 竖排右对齐，英文横排小字缀底 | 东方、节气、山水 |
| 中英咬合 | 英文小字嵌行间或低透明度叠印 | 双语海报 |
| 留白嵌字 | 标题整体放负空间，零叠压 | 极简高留白 |
| 沿结构线生长 | 文案顺花茎/枝条/地平线排布，小字大距分级 | 节气、主体特写 |
| 主体当立轴 | 树干/光柱作贯穿轴，文字悬挂两侧 | 单主体极简、禅意 |
| 散点呼吸 | slogan 拆成中英小短语对角线散钉 | 禅意、生活方式 |
| 上下锚点 | 顶部拼音拉开+底部英文收尾，中央嵌字 | 节气三明治 |
| 日历信息组 | 大字星期+((年))+长横线牵引日期，字色随区反转 | 日系、旅行、日记 |

字体气质三选一：细宋（横细竖粗、Light、衬角锐利）｜手写行楷/瘦金（连笔、飞白、笔画拉长）｜毛笔书法大字（只用于单字或超大主字）。西文：Didot 类高对比衬线、衬线斜体、花体首字母。

字色策略三选一（代替底色）：白字压暗部（明度对比）｜主色深一档同色系（深苔绿/玫红/金/墨绿）｜深灰墨字放浅色负空间。

融合手法：直接叠加靠暗部｜英文 30%–60% 透明度叠印半溶｜字边缘被雾气轻咬｜零叠压嵌字｜同色勾线沿山势呼应字迹｜手写长拖笔方向=画面动势（字势即景势）｜实物小图嵌句中当活字｜文字落在褶皱布面侧光里｜拟声词字号渐隐斜排｜假名/符号插入标题作顿挫。标题避开几何正中，占宽 50%–80%；单字约画面宽 1/10，核心大字可到 1/4 以上。

提示词短语：

```text

one oversized calligraphy character, its long final stroke running through the frame
thin elegant Songti serif, light weight, sharp serifs
handwritten thin-pen script with extended strokes and flying white

letters half-dissolved into the mist; no color block behind text, no outline, no glow

slogan fragments scattered as diagonal whispers around the central title

```

选择逻辑：书法/手写→情绪浓的个人化主题；细宋→节气、自然观察、安静知性；大小对比/长笔画→单字点题。每张只选 1 骨架 + 1 字体 + 1 字色策略。

## 常用元素速查

蕉叶/大叶片、细枝、模糊花影、草地、海平线/水面、飞鸟（2–5 只小剪影）、光晕、雾/薄纱、
树影、小人物背影、月亮/太阳、水纹/风纹、纸张纤维、印章小符号、蝴蝶/蛾（幽光处理）、
茶器（配运动模糊）、湿窗雨痕。

每张限用：1 主元素 + 0–2 辅助元素 + 1 种主笔触 + 1 个光线焦点 + 1 组配色。
元素可系列化轮换：固定风格系统，只换主角（如大海→海平线→水纹→潮痕）。

## 交付前检查清单

- [ ] 只有一个清晰的主意象？
- [ ] 至少 1/3 呼吸空间？
- [ ] 主色低饱和不刺眼？
- [ ] 有一个自然柔和的光线焦点？
- [ ] 主体边缘足够柔？
- [ ] 有颗粒/纸张/雾感但不过度滤镜？
- [ ] 文字区干净，后期排版有空间？
- [ ] 字体不超过三种且授权清晰？字距疏朗？
- [ ] 无商业广告、电商主图、信息堆叠？
- [ ] 先感到情绪，再看懂主题？

最终判断：删掉一半元素更好看就删；颜色漂亮但没有空气感就降饱和；主体清楚但没有情绪就加雾、
加距离、加留白；文字抢过意象就把字变轻变小变疏。
