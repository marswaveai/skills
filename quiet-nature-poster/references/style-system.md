# 静谧自然海报风格系统

> 用途：以后只要输入「主题」或「配色」，就能快速生成同一审美体系下的海报提示词。  
> 核心方向：低饱和自然意象 × 东方日系留白 × 胶片/纸张质感 × 诗意排版。

---

## 1. 一句话定义

这是一套**把自然景物处理成情绪背景**的海报风格：不追求把东西拍清楚，而是用被雾、光、纸张和颗粒柔化过的单一自然元素，配合克制的文字与大面积留白，让画面像一段被保存下来的季节记忆。

关键词：

`安静` `低饱和` `自然` `朦胧` `留白` `胶片颗粒` `纸张触感` `东方极简` `日系杂志` `诗意` `轻微忧郁` `慢生活`

### 不变的风格底线

1. **情绪优先于信息密度**：画面先让人感受到季节、温度和距离，再传递主题。
2. **一个主意象就够了**：主物体不要堆叠，宁可留空，也不要把画面填满。
3. **柔化边缘**：少用锐利、硬朗、商业产品图式的清晰边界。
4. **颜色要收敛**：以低饱和邻近色为主，最多保留一个小面积强调色。
5. **文字参与构图**：文字不是后贴的说明，而是和自然意象共同构成画面秩序。
6. **保留一点不确定性**：允许模糊、颗粒、晕染、留白和不可完全解释的光。

## 2. 整体视觉指纹

| 维度 | 推荐方向 | 应避免 |
|---|---|---|
| 画幅 | 竖版 2:3、4:5、9:16；必要时横版 3:2 | 过度拥挤的方形商业构图 |
| 主体 | 一片叶、一枝花、草地、海平线、飞鸟、光斑、远处小人 | 多主体、多物件、多场景同时出现 |
| 清晰度 | 柔焦、失焦、动态模糊、轻微朦胧 | 超高清锐化、过度 HDR、强轮廓 |
| 色彩 | 莫兰迪、雾感、同色系、自然大地色 | 霓虹、高饱和撞色、纯黑纯白大面积对撞 |
| 光线 | 逆光、薄雾光、漫射光、局部光晕、低对比自然光 | 硬闪、强烈棚拍光、金属高光 |
| 材质 | 胶片颗粒、哑光纸、宣纸、磨砂玻璃、轻微尘埃 | 塑料感、玻璃高光、过度干净的数码渐变 |
| 版式 | 中轴、疏朗、非对称平衡、上下呼吸 | 信息卡片式、满版营销字、复杂装饰框 |
| 情绪 | 清凉、宁静、知性、温柔、远方、内省 | 热闹、甜腻、强烈励志、喧哗促销 |

## 3. 构图规律

### 3.1 空间比例

可把画面大致分成三种区域：

- **自然意象区：35%–55%**：承载季节和情绪，不一定是清晰主体。
- **文字区：10%–20%**：标题、英文辅助信息、日期或短句。
- **留白区：25%–45%**：让主体和文字有呼吸，避免“设计做满”。

这不是硬性像素规则，而是视觉密度的控制原则。

### 3.2 六种可复用构图骨架

#### A. 中轴悬浮

- 适合：春天、夏天、节气、生活方式主题。
- 做法：自然背景虚化，标题置于画面中央，副文案少量分布在上下或右侧。
- 感受：稳定、温柔、像一张书签。

#### B. 上实下虚

- 适合：春分、秋日、植物、生长、寻找方向。
- 做法：上方放一块叶片、树影或流动笔触，下方大面积留白放文字。
- 感受：有方向感，轻微向下沉静。

#### C. 对角线意象

- 适合：蕉叶、枝条、风、雨、迁徙、旅行。
- 做法：一片叶、一枝枝干或一条水纹从左上到右下穿过画面，标题沿空白区域布置。
- 感受：静中有动，避免过于呆板。

#### D. 低位地平线

- 适合：海、远方、告别、夏日、自由、孤独。
- 做法：海平线放在下方 1/3，天空占大部分空间，文字像漂浮在空气中。
- 感受：辽阔、清冷、克制。

#### E. 偏侧留白

- 适合：花朵、枝叶、香氛、品牌主题。
- 做法：主体只占左侧或右侧 1/3，另一侧保留完整呼吸区放标题。
- 感受：高级、安静、可用于品牌海报。

#### F. 小人物远景

- 适合：独处、夜晚、回家、等待、自我寻找。
- 做法：人物只作为很小的比例尺，置于大面积自然空间中；不要画成肖像主角。
- 感受：孤独但不绝望，有陪伴感和故事余地。

### 3.3 构图判断口诀

> **先找呼吸区，再放主意象；先定情绪重心，再放标题；画面宁可空三分，不要满到没有回声。**

## 4. 文字与排版规律

### 4.1 标题结构

推荐把文字拆成三层：

1. **主标题**：2–6 个汉字，承担情绪和视觉重心，例如「春和花野」「风从海上来」「慢慢发光」。
2. **辅助英文**：1–4 个单词，作为节奏和版式补充，例如 `SPRING / STILLNESS / TOWARD LIGHT`。
3. **小信息**：日期、节气、地点、短句或极短说明，字号明显小于标题。

主标题不要写成完整宣传语。若主题复杂，把信息放到副文案，标题只保留最有画面感的词。

### 4.2 字体组合

- **中文主标题**：细宋体、现代宋体、带书卷气的衬线体、克制的书法字。
- **中文副文案**：细黑体或更小的宋体，保持易读。
- **英文辅助**：细衬线体、窄体无衬线体、轻微手写体或斜体。
- **字体数量**：最多 2–3 种；一套海报里不要同时出现粗黑体、圆体、手写体、装饰体。

### 4.2.1 字体版权安全

默认只使用**开源、可商用或已确认授权**的字体。提示词优先描述字体气质，不依赖某个未授权的商业字体名称。

推荐的低风险字体方向：

- **中文衬线**：思源宋体 / Source Han Serif，Noto Serif CJK；
- **中文无衬线**：思源黑体 / Source Han Sans，Noto Sans CJK；
- **中文手写感**：优先选择授权清晰的开源手写字体；没有确认授权时，只描述为“克制的手写笔触”，后期替换；
- **英文衬线**：Source Serif、Noto Serif；
- **英文无衬线**：Inter、IBM Plex Sans、Noto Sans。

使用规则：

1. 商业项目、公开发布或客户交付时，先确认字体的授权范围、是否允许商用、是否需要署名。
2. 不把“网上能下载”当作“可以商用”，字体文件来源和授权说明要能追溯。
3. AI 生成的文字无法证明字体授权，也不能视为最终可直接使用的字体成品；正式海报应后期使用已确认授权的字体重新排版。
4. 如果无法确定某个字体是否合规，使用通用风格描述或替换为已确认授权的开源字体。

### 4.3 排版动作

- 标题可居中，也可沿中轴略微错位。
- 竖排文字适合东方、节气、自然、茶、香氛等主题。
- 英文可以作为细小的横向基线，给中文竖排增加现代感。
- 字间距要宽，行距要松，文字之间保留空气。
- 标题颜色不必纯白，可用米白、灰绿、雾蓝、褪色棕等与背景相连的颜色。
- 辅助信息可以放在边缘、角落或主体的空白处，但不要形成“信息栏”。
- 文字块应像画面中的一件物体，而不是贴在图片上的标签。

### 4.4 AI 生成文字的现实约束

图像模型经常无法稳定生成可读中文，也无法可靠证明生成字体的授权状态。提示词里应明确：

- 若只需要风格图：`保留清晰的空白排版区域，不生成乱码文字，文字后期使用已确认授权的字体添加`。
- 若必须生成标题：只放极短标题，写明`仅生成“春天”两个汉字，字形简洁可读`；生成结果只作为构图参考，正式发布前用已授权字体重排。
- 正式海报优先采用：**先生成无字底图 → 再用已确认授权的开源字体排版 → 最后检查字库授权和商用范围**。
- 不要在最终提示词中依赖未确认授权的商业字体名称；改用`细宋体气质`、`现代衬线体`、`克制的手写笔触`等视觉描述，或直接指定已确认授权的开源字体。

### 4.5 主题文案扩展

当你只提供主题时，配版文案不局限于主题词本身。我会先判断主题的情绪，再给出适合排版的短标题、副文案和可选引用方向。

#### 文案来源优先级

1. **原创短句**：默认优先。根据主题写 3–5 组克制、具体、有画面感的短句，避免与现成作品过度相似。
2. **公共领域文本**：可以参考已进入公共领域的诗句、散文或文学意象，并注明作者和作品信息。
3. **你提供的原文片段**：你可以直接给我歌词、台词或诗句片段，我可以帮你筛选长度、断行、改成适合海报的版式。
4. **现代版权作品的方向化参考**：如果你只给作品名或作者名，我可以提炼其主题情绪、意象方向和叙事功能，改写成全新的原创海报文案；不会默认补出大段受版权保护的原文。

#### 文案的气质要求

- 少用“愿你”“热爱生活”“一切美好如期而至”等泛化鸡汤。
- 少用被反复转载的名人金句和已经形成固定记忆点的经典句式。
- 多使用具体的自然细节、动作、距离、时间和触感，例如风、潮痕、窗光、旧纸、未寄出的信。
- 允许句子不完整、留白和轻微含混，不把情绪解释到底。
- 文字要短：主标题 2–6 字，副句通常 8–24 字，英文辅助 1–4 个词。
- 语气以克制、清醒、含蓄为主，可以有忧郁，但不写成用力过猛的伤感文案。
- **控制词藻密度**：一个标题或副句通常只保留一个核心意象和一个情绪动作；避免连续使用“静谧、清冷、温柔、朦胧、深邃”等抽象形容词。
- **让画面承担一部分诗意**：文字不必把氛围全部说完，能由海平线、窗光、潮痕、叶影或一处微光表达的内容，就不要重复写进文案。
- **优先自然口吻**：句子可以简单、短促，甚至保留一点口语感；有余韵比有生僻词更重要。
- **避免故作深沉**：不为了“高级”而牺牲清晰度，不写无法对应到画面元素的空泛抒情。

#### 默认输出的文案组合

每次主题配版默认给出：

- **诗意主标题**：2–8 字，适合放在视觉中心；
- **原创副句**：2–3 条，供你挑选；
- **引用方向**：如“旧歌式的告别感”“电影对白式的克制”“散文式的季节观察”，必要时再由你提供原文；
- **排版建议**：横排或竖排、断行位置、字数和留白关系。

#### 主题命名与文字的诗意原则

- 宽泛或功能性的主题，先转译成**有画面、有关系、有动作或有余韵**的诗意命名，再补充必要的场景解释。
- 例如“夜晚独自整理自己”优先命名为**“我”的独处约会**；“告别夏天”可以拓展为“把夏天留在潮痕里”“风替我说再见”；“重新开始”可以拓展为“在晨光抵达之前”“从一枚新叶开始”。
- 主题名不必把情绪解释完整，可以保留一点含混，让画面、元素和文案共同完成叙事。
- 避免工作说明式命名，例如“夜晚/独处海报”“春天主题设计”“治愈系生活方式”；这些可以作为内部标签，不作为最终海报标题。
- 诗意不等于堆砌华丽词语：优先使用具体的自然细节、时间、动作、距离、关系和轻微转折。
- 每次拓展宽泛主题时，默认提供 4–6 个诗意方向名，并在括号或副行中保留清晰的场景说明，兼顾美感与可执行性。


#### 强制文字规则

- 如果你在输入中标注“强制文字”或直接给出必须保留的文字，必须**逐字保留**，包括汉字、英文、数字、标点、大小写和换行要求。
- 强制文字的优先级高于自动创作文案；可以调整字体、字号、颜色、位置和断行，但不能擅自改写、删减或替换。
- 若图像模型无法稳定生成准确文字，先生成对应的无字底图和明确文字区，再用已确认授权的字体后期嵌入；最终海报仍必须包含这段强制文字。
- 若没有强制文字，才自动拓展原创标题、副句和少量英文、数字或符号。

#### 英文、数字与符号

- 只在有排版需要时少量加入，通常控制为 1–4 个英文词、一个年份/日期或一个简洁符号。
- 英文和数字承担节奏、时间、地点或主题索引的作用，不单独制造商业感。
- 符号优先使用细小的点、短线、括号、斜杠或简单印记，避免装饰堆叠。

## 5. 配色规律

### 5.1 基本配色比例

- **主色 60%–75%**：来自背景或大面积自然元素。
- **辅助色 20%–30%**：来自雾、纸张、阴影或次级植物色。
- **强调色 3%–8%**：只用于微小光点、印章、花心、夕阳或一处文字。

整体优先使用邻近色。对比应来自明度、透明度和材质，而不是强烈的互补色碰撞。

### 5.3 从用户提供的图片配色自动适配

以后若只收到一张配色图，可以按以下规则转译：

1. 取图中最大面积的颜色作为**主色**，降低饱和度 10%–25%。
2. 从阴影或最深处取**辅助深色**，用于文字或构图重心。
3. 从高光或纸张区域取**留白色**，不要直接使用纯白。
4. 从画面中最小面积的亮色取**强调色**，控制在 3%–8%。
5. 若原图颜色太鲜艳，先转为灰调、雾化、降低对比，再保持色相关系。
6. 不改变这套风格的明度层级：背景要能呼吸，标题要能读，强调色只能轻轻出现。

### 5.4 新增元素与色板的调用方式

- 主题偏清凉、通透、当代：优先调用**冷透薄荷**，主元素选择磨砂流体、水纹或薄纱。
- 主题偏春游、漫游、轻怀旧：优先调用**颗粒春游**，主元素选择远景人物、草地、飞鸟或小船。
- 主题偏花期、安静、手作：优先调用**纸感藕粉**，主元素选择单枝花、干花、叶片或草本。
- 主题偏生长、花卉、东方自然：优先调用**绿意微距**，主元素选择露珠、半透明花瓣或失焦叶脉。
- 如果主题同时满足多个方向，保留一个主色板，另一个方向只作为 3%–8% 的强调色或辅助材质，不要平均混合。

## 6. 线条、笔触与图形语言

### 6.1 线条特征

- 细、轻、疏，不追求机械几何的绝对规整。
- 线条可有轻微断续、晕染、干笔、毛边和透明度变化。
- 植物轮廓不要勾得太完整，允许边缘融入雾和背景。
- 装饰线只做方向提示或视觉呼吸，不做复杂花边。
- 线条颜色优先使用比背景更深一档的同色系，而不是纯黑。

### 6.2 可调用的笔触类型

| 笔触 | 视觉作用 | 适用元素 |
|---|---|---|
| 水墨晕染 | 让形体融入空间 | 叶片、山、云、远景 |
| 干刷擦痕 | 增加纸面和时间感 | 秋、土地、风、旧记忆 |
| 透明细线 | 提供秩序与现代感 | 框线、枝条、英文排版 |
| 柔软弧线 | 表示流动、风和呼吸 | 水面、光线、草叶 |
| 稀疏手绘线 | 增加人的温度 | 飞鸟、微小人物、枝叶 |
| 低透明度色块 | 建立朦胧层次 | 花影、雾、光斑、背景 |

### 6.3 不要出现

`粗黑描边`、`卡通涂鸦`、`复杂装饰边框`、`高精度矢量图标`、`强烈漫画阴影`、`大量花瓣堆叠`、`过多小元素抢主体`。

## 7. 单一元素拆解库

| 单一元素 | 画面功能 | 推荐处理 | 常用位置 | 关联情绪 |
|---|---|---|---|---|
| 一片蕉叶/大叶片 | 建立季节与东方气质 | 放大、柔焦、局部出画、边缘水墨化 | 左上斜入或侧边 | 清凉、午后、闲适 |
| 一枝细枝 | 提供方向和秩序 | 细线、低对比、少量叶片 | 右侧或顶部伸入 | 克制、等待、春意 |
| 一朵模糊花 | 提供柔软的色彩中心 | 只保留花影和色块，不画清花瓣 | 偏侧或中央后方 | 温柔、浪漫、记忆 |
| 草地/草丛 | 让画面有呼吸和风感 | 动态模糊、长曝光、压低细节 | 横向铺底或下半区 | 自由、夏日、松弛 |
| 海平线/水面 | 制造远方和空间 | 低位水平线、轻颗粒、低对比 | 下方 1/3 | 清凉、辽阔、告别 |
| 飞鸟 | 提供极小的动态和叙事 | 只用 2–5 个小剪影，排成弧线 | 远景或留白区 | 远行、自由、希望 |
| 光晕/发光点 | 作为唯一视觉焦点 | 柔和、扩散、不过曝 | 中央或远景 | 指引、治愈、神秘 |
| 雾/薄纱 | 统一画面并降低锐度 | 半透明叠加，保留层次 | 全画面或主体后方 | 疏离、梦境、安静 |
| 树影 | 用影子代替实体 | 模糊、倒置、局部遮挡 | 顶部或背景 | 自然、时间、沉思 |
| 小人物背影 | 提供尺度和故事 | 很小、远景、不展示脸 | 地平线或底部 | 独处、寻找、回家 |
| 月亮/太阳 | 形成季节和时间提示 | 小面积、低亮度、光晕化 | 上方留白 | 夜、清晨、等待 |
| 水纹/风纹 | 让静态画面有流动 | 极简曲线、拉伸模糊 | 底部或斜向穿过 | 流逝、呼吸、轻盈 |
| 纸张纤维 | 把数字图变得可触摸 | 细颗粒、哑光、低透明度 | 全画面底层 | 手作、旧物、温度 |
| 印章/小符号 | 增加东方设计落点 | 只用一个小小的色块或印记 | 角落或标题旁 | 文化感、完成感 |

### 元素组合限制

默认每张海报只选择：

- 1 个主元素；
- 0–2 个辅助元素；
- 1 种主要笔触；
- 1 个光线焦点；
- 1 组配色。

例如：`蕉叶 + 细线文字 + 米纸蕉叶配色`，不要再同时加入花、鸟、人物、建筑和器物。

### 7.1 多参考图与系列化拓展

当你提供多张参考图时，先区分两类信息：

1. **共同风格信息**：反复出现的色彩、留白比例、颗粒、虚焦、字体气质、光线方向和版式秩序，作为整组海报的固定系统。
2. **显著主题元素**：例如大海、蝴蝶、蕉叶、飞鸟、窗光等，提炼成可替换的主元素，并统一转换成这套画风的低饱和、柔焦、纸面或水墨质感。

系列化处理遵循：

- 固定配色逻辑、材质、字体层级和留白习惯，只替换主元素或一个辅助元素。
- 每张海报保持“一个主元素”的单一化，但同一系列可以让主元素依次变化。
- 先提炼元素的**形态、动作、位置和情绪功能**，再做风格化，不直接复制参考图的具体构图。
- 如果参考图里有大海，可拓展为海平线、水纹、浪花、潮痕、远船；如果有蝴蝶，可拓展为单只蝴蝶、翅影、飞行轨迹、停在枝头的局部，但每张只选其中一个作为主角。
- 默认输出“核心版本 + 2 个同画风变体”，方便后续制作连续海报。

## 8. 相似风格的拓展方向

### 8.1 雾森治愈

- 元素：露水、苔藓、远处鸟群、树间白光。
- 配色：雾森青、灰绿、米白。

### 8.2 海风空镜

- 元素：低位海平线、薄云、白色浪花、远处小船。
- 配色：海风灰蓝、浅灰、褪色白。
- 适合：夏天、自由、告别、去远方。

### 8.3 秋日纸墨

- 元素：干草、麦穗、枯枝、烟雾、茶汤般的光。
- 配色：秋日麦光、纸米色、深棕。
- 适合：秋、成熟、阅读、沉淀。

### 8.4 深夜微光

- 元素：深蓝背景、很小的人影、窗光、月亮、下坠线条。
- 配色：深夜靛蓝、灰白、少量冷银。
- 适合：孤独、梦、等待、自我整理。

### 8.5 花野书签

- 元素：失焦花影、散落花瓣、细枝、轻薄文字。
- 配色：春雾花野、远山灰粉。
- 适合：关系、春日、温柔、女性向生活方式。

### 8.6 新中式自然

- 元素：蕉叶、飞鸟、山石、纸面、书法线条。
- 配色：米纸蕉叶、深苔绿、墨灰。
- 适合：茶、香氛、节气、文化活动、文创品牌。

---

### 8.7 冷透磨砂流体

- **主元素**：半透明波浪、玻璃状流体、折射的水纹、轻薄织物般的抽象形体。
- **色彩**：湖蓝、薄荷绿、雾白为主，可用深灰或墨黑文字锚定画面；参考 `#DCEBE6 #A9D2CB #78AEB7 #273B3E`。
- **构图**：大面积浅色背景，流体在中心或下半区形成柔和的 S 型动势，四角和底部保留排版空间。
- **光线**：漫射光、柔和折射、轻微彩色边缘色散，不要强烈玻璃高光。
- **材质**：磨砂玻璃、半透明树脂、水波折射、细腻颗粒；透明但不塑料。
- **情绪**：清凉、通透、疏离、现代、像夏日空气被凝固。
- **可替换元素**：流体可替换为水面、薄纱、云雾、花瓣轮廓或抽象风的轨迹，但保持单一形体。

### 8.8 颗粒春游与漫游人物

- **主元素**：远处模糊人物、行走剪影、被风吹动的草地或大面积浅蓝天空。
- **色彩**：浅天蓝、嫩草绿、灰白，少量较深的蓝色用于标题；参考 `#C9DFE1 #AFCB9B #EEF0E5 #3D7191`。
- **构图**：人物置于左上或远景，超大标题压在右下或下半区，形成对角线平衡；人物不可占画面过大。
- **光线**：春日午后漫射光，低对比、稍微过曝但不刺眼。
- **材质**：明显但细腻的胶片颗粒、旧印刷噪点、柔焦和轻微褪色。
- **排版**：可以使用一处超大中文标题作为图形锚点，搭配少量小英文或日期；标题采用已确认授权的开源书法/衬线字体后期排版。
- **情绪**：漫游、春日、轻盈、怀旧、与世界保持一点距离。
- **可替换元素**：远处人物可替换为小船、飞鸟、自行车或一把空椅子，但仍保持小比例和远景叙事。

### 8.9 纸感单枝花卉

- **主元素**：一枝细长花卉、干花、草本、果枝或一件纤细的单体物件。
- **色彩**：暖灰米色背景、淡藕粉花瓣、柔棕枝茎和一点鹅黄色花心；参考 `#E2D9D0 #D0A9AA #9D806D #D4B86F`。
- **构图**：主体偏右或沿黄金分割向上伸展，背景留白至少 40%，花枝形成向上的垂直节奏。
- **光线**：柔和漫射光，阴影轻，避免商业棚拍感。
- **材质**：哑光纸张、旧宣纸颗粒、色铅笔或细密素描笔触，边缘带轻微毛边，不要变成锋利矢量插画。
- **排版**：细字距、细无衬线体或现代衬线体，标题与花枝保持距离；可用一个小圆点、短线或日期作索引。
- **情绪**：安静、克制、温润、慢生活、被保存的花期。
- **可替换元素**：花卉可以替换为叶片、麦穗、蕨类、果实或一支香草，但一张图只保留一个主物件。

### 8.10 绿意微距与书法压字

- **主元素**：失焦花卉、半透明花瓣、露珠、绿色背景中的局部植物肌理。
- **色彩**：翠绿、奶白、墨黑三色为主，少量花蕊暖色点睛；参考 `#7EA568 #F3F1E7 #243126 #D8B96D`。
- **构图**：垂直长构图，顶部标题区、中部花卉视觉中心、底部留白和小信息区；主花可被画面裁切，不要求完整展示。
- **光线**：侧逆光或穿透花瓣的柔光，突出水珠和半透明质感；背景继续保持大幅虚焦。
- **材质**：微距摄影、细小露珠、柔焦、胶片颗粒和湿润有机表面。
- **排版**：大号书法字或手写笔触作为图形压在背景上，搭配纤细的现代衬线/无衬线小字；正式发布时使用授权清晰的字体后期叠加，避免直接依赖 AI 生成文字。
- **情绪**：生机、治愈、东方禅意、柔软但有力量。
- **可替换元素**：花卉可换成叶脉、露珠、苔藓或果实，保持一处微距焦点和一处书法文字锚点。

### 8.11 新增参考图的共通修正

这组图说明“静谧自然”不只等于雾绿和模糊摄影，还可以容纳两种对比方向：

1. **冷透的现代感**：磨砂玻璃、流体折射和更干净的浅色背景，适合夏日、清凉、未来感自然主题。
2. **手作的温度**：纸张、色铅笔、书法压字和旧印刷颗粒，适合花、春日、节气、慢生活主题。
3. **结构化的编辑感**：档案编号、边角信息、圆形视窗和网格文字可以作为实验分支，但需要降低密度，保留主意象和呼吸区。
4. **更深的电影感**：深蓝、深绿、低位人物、远景鸟群和湿地反光可以把情绪推向孤独与沉思，但仍要避免过度戏剧化。

保持系列统一时，固定以下项目：低饱和色彩、柔化边缘、大面积留白、轻颗粒、一个主元素、少量文字。变化只放在主元素材质、光线冷暖、标题尺度和构图方向上。

### 8.12 水彩冷压纸与节气风景

- **主元素**：霜、雪坡、远山、稀疏树影、雾中的建筑轮廓或一小群飞鸟。
- **色彩**：冷雾雪蓝，允许从浅雾白过渡到深灰蓝，避免鲜艳纯蓝。
- **构图**：竖版长画幅，主体压到下方 1/3 或更低，上方保留 60% 左右的天空、雾或纸面空间。
- **材质**：水彩冷压纸、干湿交叠的晕染、细纸纤维、少量颗粒；不要做成光滑数码渐变。
- **文字**：节气名可用大号中文或细衬线英文置于中轴，日期和地点放在边角；正式发布仍以后期授权字体为准。
- **情绪**：冷清、辽阔、季节转换、安静到近乎无人的自然。

### 8.13 抽象刮板与拖拽颜料

- **主元素**：一条被刮板拉开的颜料带、半透明色层、斜向折痕或抽象风的痕迹。
- **色彩**：根据主题选一个窄色域，例如雾绿、灰蓝、灰粉或土黄；强调色只保留一小条。
- **构图**：斜向或横向拖拽，形成一条方向性动势，其余区域保持平静留白。
- **材质**：水彩、油画刮痕、纸面摩擦、边缘堆积和不均匀透明度；保留手作偶然性。
- **文字**：细小文字沿拖拽方向或置于空白侧，避免和笔触争夺中心。
- **情绪**：流动、风、时间、未完成、抽象的季节感。

### 8.14 冷雾深蓝电影感

- **主元素**：雾中的远景人物、湿地、雪地、树影、远处城市或一条暗色海岸线。
- **色彩**：冷雾雪蓝、深夜靛蓝或钢蓝灰，浅色只作为雾层和文字。
- **构图**：低位主体 + 大面积上方留白，或上半部文字、下半部风景的双层画廊结构。
- **材质**：35mm 胶片颗粒、湿地反光、低清晰度远景、柔和暗部；不使用强烈电影光束。
- **文字**：中文书法/衬线标题与细英文、日期或坐标搭配，文字层级清晰但不满版。
- **情绪**：孤独、冷静、告别、人在自然尺度中的渺小。

### 8.15 深林幽光与蝴蝶/蛾

- **主元素**：一只蝴蝶、蛾、翅影或小型夜行生物，作为低亮度的幽光焦点。
- **色彩**：深林幽光，主体可以使用灰白、浅苔绿或极少量冷黄，不要做成荧光昆虫插画。
- **构图**：深色背景中让主体悬浮，标题居中或偏侧，辅以一条细弧线、环形轨迹或很小的符号。
- **材质**：软焦、炭笔擦痕、长曝光、低透明度翅影和颗粒暗部，禁止硬描边。
- **文字**：可以使用一个英文主题词和一行较短的诗意副句；如涉及现成歌词，只做方向化改写或使用用户提供的片段。
- **情绪**：脆弱、亲密、梦境、怀旧、轻微忧郁。

### 8.16 圆形视窗与档案拼贴

- **主元素**：一个自然物的局部视窗，例如花、叶、建筑纹理、昆虫翅膀或微距表面。
- **构图**：在米白或灰阶底面上叠加 1–3 个圆形/椭圆形视窗，视窗大小错落但不堆叠；文字采用网格或边角对齐。
- **色彩**：档案灰阶最稳妥，也可把整组视窗统一染成橄榄绿、灰蓝或暖褐。
- **材质**：铅笔线稿、扫描纸、透明胶片、轻微套印偏移和颗粒噪声。
- **文字**：主标题大而少，说明文字像图鉴条目；可加入年份、编号、坐标或拉丁式分类符号，但控制数量。
- **情绪**：观察、研究、冷静、实验性、设计档案感。
- **边界**：这是可选的结构分支，不作为所有海报的默认版式；主题需要安静自然时，优先回到留白构图。

### 8.17 茶器与运动模糊

- **主元素**：一只陶瓷茶杯、茶壶、杯沿蒸汽或一件安静的器物。
- **构图**：器物保持相对清晰，旁边只加入一条花枝、手部动作或花瓣的运动模糊，形成“静止与流逝”的对照。
- **色彩**：茶器暖岩、暖米、柔棕或灰绿，不使用高饱和橙色。
- **材质**：陶土哑光、纸面颗粒、柔和长影、局部拖影和自然反光。
- **情绪**：仪式、等待、时间沉淀、东方生活美学。

### 8.18 玫瑰薄雾与星座式文字

- **主元素**：一朵失焦花影、花瓣轮廓或中央的植物剪影。
- **构图**：中心有一个稳定锚点，周围把少量中文、英文和短句拆成不规则文字簇，像漂浮的星座；留白仍然大于文字量。
- **色彩**：玫瑰薄雾或远山灰粉，文字使用低对比深玫瑰，不要纯黑压住画面。
- **材质**：柔焦渐变、砂纸颗粒、纸面噪声和边缘溶解。
- **情绪**：春日、温柔、关系、记忆、轻微含混。

### 8.19 模式体系：一个基础 + 四个可叠加项

新参考图中出现的档案网格、圆形视窗、强结构数据字、深色电影感和青柠强调色，不应覆盖原有主风格。为避免概念混乱，模式不再平级并列，而是拆成「一个基础底色 + 四个可叠加项」：

**基础底色（永远生效）：安静自然**

- 所有海报的共同底层：低饱和、柔焦、大面积留白、轻颗粒、一个主元素、克制文字。
- 不加任何叠加项时，就是最初的谧静自然风格。

**四个可叠加项（按需开启，每张最多同时两项）**

| 叠加项 | 只改什么 | 加进来会怎样 | 什么时候用 | 触发词示例 |
|---|---|---|---|---|
| 编辑排版 | 版式 | 超大标题、双层画廊结构、细英文基线，画面更像杂志内页 | 节气专题、品牌月报、系列封面 | 杂志感、标题大一点、编辑风 |
| 档案图鉴 | 信息结构 | 编号、年份、圆形视窗、图注小字，画面像标本卡 | 图鉴、研究记录、展览、文创 | 档案、图鉴、编号、标本 |
| 电影夜色 | 光色与明暗 | 整体变深蓝/深绿，暗部颗粒更厚，主体压到低位 | 雨夜、告别、孤独、冬季 | 夜、电影感、暗一点 |
| 实验笔触 | 材质技法 | 刮板颜料、透明叠层、套印偏移，或加入青柠强调色 | 抽象季节、先锋编辑、当代艺术 | 抽象、实验、颜料 |

**组合规则**

1. 默认只开「安静自然」，不加任何叠加项；只有主题明确需要时才叠。
2. 表述方式写作「安静自然 + 叠加项」，例如「安静自然 + 电影夜色」。
3. 每张最多叠 1–2 项；叠得越多离「安静」越远，需要更强的理由。
4. 推荐组合：「档案图鉴 × 电影夜色」（深夜标本感）、「实验笔触 × 编辑排版」；「档案 × 实验」容易杂，慎用。
5. 同一主题下切换叠加项只改变对应维度，其余规则不变。例如主题「霜降」：仅基础是雾白雪坡与细树影；+编辑排版则超大「霜降」压在下方；+电影夜色则整体沉入深蓝暮色。

未指定时一律视为纯基础；用户说“暗一点”“像杂志”等口语时，映射到对应叠加项并向用户确认。

### 10.1 主题情绪自动配色

当你只提供主题，没有指定配色时，先判断主题的**季节感、情绪温度、距离感和明暗倾向**，再从风格库中选择或组合配色。默认不使用高饱和色，不让颜色喧宾夺主。

| 主题情绪 | 自动配色方向 | 画面倾向 |
|---|---|---|
| 新生、春天、开始、希望 | 雾森青 + 淡粉 + 米白 | 新叶、花影、晨光、上实下虚 |
| 夏日、自由、风、远方 | 海风灰蓝 + 褪白 + 草木绿 | 海平线、草丛、飞鸟、大片天空 |
| 温柔、关系、花、相遇 | 灰粉 + 雾绿 + 暖米色 | 失焦花影、细枝、柔光、偏侧留白 |
| 秋天、成熟、阅读、沉淀 | 麦芽黄 + 琥珀 + 纸米色 + 深棕 | 干草、茶汤光、纸张、垂直中轴 |

#### 自动配色的四步逻辑

1. **先定温度**：主题偏清凉，就向灰蓝、雾绿移动；主题偏温暖，就向米色、麦芽黄和灰棕移动。
2. **再定明度**：希望和开始使用较亮的纸米色；独处和沉思使用更深的蓝灰，但必须保留一处可呼吸的浅色。
3. **最后定强调色**：只从主题中挑一个小面积亮点，例如春天的淡粉、秋天的琥珀、夜晚的冷白光。
4. **统一材质**：无论主题是什么，都保留低饱和、柔焦、颗粒和哑光触感，避免变成普通的商业配色海报。

若主题含义模糊，会优先选择**雾森青 + 米白**作为基础方案，再根据关键词向冷蓝、灰粉或麦芽色偏移。若你提供了配色图片，则以图片为主，主题情绪只负责调整明度、饱和度和强调色面积。

### 默认参数

如果你没有提供某项，默认使用：

- 画幅：竖版 2:3；
- 主元素：一个自然意象；
- 构图：偏侧留白或中轴悬浮；
- 配色：先根据主题情绪判断，再选择低饱和邻近色；
- 光线：柔和漫射光；
- 材质：轻胶片颗粒 + 哑光纸张；
- 文字：预留后期排版区，不强行生成可读中文；
- 情绪：安静、克制、诗意，不过度伤感。

### 10.2 宽泛主题的具象化拓展

当你给出的是“春天、自由、孤独、夏日、回家”这类较大的主题，且没有指定强制文字、固定人物、固定场景或不可改变的元素，我会先把它拓展成 4–6 个更具体的方向，再进入正式海报提示词生成。

每个方向都会包含：

- **具体主题名**：让画面有清晰的叙事入口；
- **一句主题解释**：说明它和原始大主题的关系；
- **主元素**：只选一个最重要的视觉抓手；
- **构图与情绪**：说明画面怎么放、想让人感受到什么；
- **自动配色**：根据具体方向重新判断，而不是所有方向共用一种颜色；
- **文案方向**：给出原创标题、副句或引用气质。

例如你只说“春天”，可以先拓展为：

| 具体方向 | 主元素 | 构图与情绪 | 配色倾向 |
|---|---|---|---|
| 春日游园 | 一枝伸入画面的新叶 | 偏侧留白，轻快但不热闹 | 雾森青 + 米白 + 少量嫩粉 |
| 我和春天有个约会 | 远处小人物或一把空椅子 | 大空间、小人物，带一点期待 | 春雾花野 + 灰绿 |
| 春日来信 | 一张被风翻动的纸或信封局部 | 纸张作为主元素，安静叙事 | 米纸色 + 淡粉 + 柔和暖灰 |
| 春分 | 光影切开的草地或一条水平线 | 虚实平衡，强调时间节点 | 灰绿 + 雾白 + 很少量暖黄 |
| 万物生 | 一枚破土的新芽 | 上实下虚，强调向上的力量 | 雾森青 + 苔藓绿 + 纸米色 |
| 落在绿意里 | 被叶影遮住的光斑 | 中轴悬浮，朦胧沉浸 | 深浅灰绿 + 一处柔白光 |

拓展时遵循三条限制：

1. 不把主题扩展成复杂故事，每个方向仍然保持一个主元素。
2. 不擅自改变强制限定；只要你指定了文字、人物、地点、颜色或构图，就以你的条件为准。
3. 方向只是帮助你选择，不会自动一次生成过多成品；你选定一个方向后，再生成核心版本和同画风变体。

## 12. 最终检查清单

生成后按这 10 项检查：

- [ ] 是否只有一个清晰的主意象？
- [ ] 是否保留了至少 1/3 的呼吸空间？
- [ ] 主色是否低饱和且不刺眼？
- [ ] 是否存在一个自然、柔和的光线焦点？
- [ ] 主体边缘是否足够柔，不像硬抠图？
- [ ] 是否有胶片、纸张或雾感，但没有过度滤镜？
- [ ] 文字区是否干净，后期排版有空间？
- [ ] 字体是否不超过三种，且字距疏朗？
- [ ] 是否避免了商业广告、电商主图和信息堆叠？
- [ ] 画面是否让人先感到一种情绪，再看懂主题？

### 最核心的判断

> 如果删掉一半元素后画面更好看，删。  
> 如果颜色很漂亮但没有空气感，降饱和。  
> 如果主体很清楚但没有情绪，加雾、加距离、加留白。  
> 如果文字抢过了自然意象，把字变轻、变小、变疏。
